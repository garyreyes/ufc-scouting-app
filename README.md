# ufc-scouting-app

A catalog of UFC fighters with personal "scouting report" notes, shared with
friends via clan-scoped groups. See [ARCHITECTURE.md](ARCHITECTURE.md) for
the full design and [CLAUDE.md](CLAUDE.md) for working conventions in this
repo.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

Other scripts: `npm run build`, `npm run start`, `npm run lint`.
